# SMTP 邮件通知

增加可选的 SMTP 通道，复用既有聊天关注、任务完成、待确认、入口和安全通知分发。只增加标准库依赖，不读取或激活其他会话，不改变会话执行归属。

SMTP 配置和投递在 `bridge/features/notifications/email.py`；共享调度继续使用原有通知通道与目的地址哈希。桌面配置支持保存、测试、凭据保留、清除及状态展示。密码只通过私有凭据 IPC 读取，轮询快照及日志脱敏。

TLS 必须验证证书，STARTTLS 不可用时失败，不自动回退明文。只有显式选择无加密才允许普通 SMTP。主机、端口、加密方式和账号组成凭据保留边界。公开错误使用固定文案，避免转发邮件服务器响应中的凭据或内容。

服务器确认 DATA 成功后，QUIT 连接清理失败不改变投递结果，避免已确认的邮件因退出超时被重复投递。连接始终关闭；认证和 DATA 阶段的失败仍报告原有的安全错误。

验证包含配置边界、SMTP 握手次序、失败脱敏、真实回环 SMTP/MIME，以及既有通知的去重和目的地址隔离回归。真实服务器测试与本机安装结果由本次任务单独记录。
