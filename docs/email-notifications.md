# 邮件通知

桌面网关的“消息通知 → 邮件通知”可以直接连接 SMTP 服务器。填写主机名、端口、加密方式、认证账号、发件邮箱和收件邮箱，开启邮件通知并保存，然后点击“发送测试邮件”。多个收件邮箱使用英文逗号分隔，最多 20 个。

加密方式支持 STARTTLS（通常为 587）、SSL/TLS（通常为 465）以及显式选择的无加密连接。以邮件服务提供的参数为准；TLS 连接始终校验服务器证书和主机名，不会在失败后自动降级。账号留空可使用无需认证的 SMTP 服务器。

邮件与现有通知通道共用聊天订阅、完成提醒、入口地址及安全事件设置。任务邮件包含通知摘要和聊天跳转链接，不发送聊天正文。后台按目的地址分别记录发送状态和重试；修改收件地址后，不会沿用旧地址的送达记录。

SMTP 密码保存在本机私有网关配置中，与既有通知凭据采用相同保存方式；不会进入轮询快照、日志或导出部署包。密码留空会保留同一服务器和账号的已保存密码。更换服务器、端口、加密方式或账号后需重新填写；清除密码时应同时关闭需要认证的邮件通道。

“邮件服务器已接受”仅表示 SMTP 服务器接受邮件，请在收件邮箱中确认实际送达，并检查垃圾邮件文件夹。
